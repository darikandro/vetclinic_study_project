### Тема проекта
Сайт ветеринарной клиники

### Версии
* Python 3.14.0 
* Django 6.0.6

### Установка зависимостей
pip install -r requirements.txt

### Применение миграций
python manage.py migrate

### Запуск сервера
python manage.py runserver

### URL проекта
http://127.0.0.1:8000/   - главная
http://127.0.0.1:8000/pricelist/  - список услуг
http://127.0.0.1:8000/doctors/  - список врачей
http://127.0.0.1:8000/clients/ - список клиентов (пока нет кнопки для этой страницы)
